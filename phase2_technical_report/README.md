## Scope and limitations

This is a Technical Report, not a runnable Phase II policy submission. It documents synchronized-data verification, leakage-controlled exploratory fitting, portable offline inference, and guarded streaming diagnostics.

The learned arm predictors reported in the PDF underperform a hold-current baseline on development validation. Robot execution remains disabled. No Phase II simulation-success or real-robot-success claim is made. Historical Phase I results in this repository are separate from these Phase II diagnostics.

The private dataset and learned weights are not published. A source-only review package can be provided to the organizers on request.
